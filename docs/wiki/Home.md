# mdview

`mdview` is a tiny, fast, local-first Markdown reader for developers, students,
technical teams, and AI-agent workflows.

The v2 goal is a polished Tauri v2 desktop app for Linux, Windows, and macOS with
native installers instead of shell-script installation.

Current status: the Tauri v2 foundation is implemented with reader, split, and
source modes; sanitized Markdown rendering; Mermaid support; recent files;
themes; print-to-PDF styling; and Linux `.deb`/`.rpm` bundle validation.
