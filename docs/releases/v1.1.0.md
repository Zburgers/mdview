# mdview v1.1.0 release notes

## Highlights

- Redesigned the desktop chrome with a centered reader/split/source switcher, animated mode indicator, refined controls, and denser app actions.
- Reworked the opening canvas so it stays centered in every mode, including split mode with no document open.
- Added a new-document source flow with an empty draft prompt instead of dropping users into a blank, unframed editor.
- Replaced the basic theme select with six theme choices and a settings panel with app/version details.
- Improved search feedback with match counts that apply to the current document in reader, source, and split workflows.
- Upgraded Mermaid handling so standalone Mermaid blocks such as `graph TD` render as diagrams, while fenced Mermaid code continues to use strict mode and sanitized SVG output.
