# mdview v1.2.1 release notes

## Highlights

- Fixed opening Markdown files directly from the system file manager through double-click or Open With.
- Added startup file recovery from the Tauri backend after the React app has mounted, avoiding the launch-time event race that left users on the empty welcome screen.
- Added single-instance routing so opening another Markdown file while mdview is already running sends that file to the existing window and focuses it.
- Preserved the Markdown/text allowlist for desktop-opened files and unsaved-change prompts before replacing an edited draft.
