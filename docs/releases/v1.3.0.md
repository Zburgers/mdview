# mdview v1.3.0 (draft)

Status: final automated qualification and Linux packaged-app smoke passed at
`f2023c4`. Release sources are prepared at `1.3.0`; Windows and macOS native
release validation and the release PR remain pending. This document is not
publication authorization.

## Rendering and navigation

- One per-render Markdown result now supplies sanitized HTML and structured
  heading, resource, and diagnostic metadata to Preview and Outline.
- Stable heading IDs and a collapsible Outline support same-document and
  document-relative Markdown navigation.
- Document-relative images include parent-folder paths, visible failure
  placeholders, and an in-app lightbox.
- Code fences use the Highlight.js common-language bundle, escaped plaintext
  fallback, language labels, and copy controls.
- Mermaid supports the pinned renderer's fenced diagram/chart types, with
  strict mode, SVG sanitization, block-local errors, expanded view, and source
  copy.
- Callouts, highlights, footnotes, bounded KaTeX math, contained tables, and
  reader styling round out the rendering surface.

## Security

Markdown and raw HTML remain untrusted. DOMPurify sanitizes parser output;
KaTeX output and Mermaid SVG have their own sanitization paths. Local links and
images are authorized by Rust, remote images remain blocked unless enabled,
and HTTP/HTTPS links still require explicit native confirmation.
